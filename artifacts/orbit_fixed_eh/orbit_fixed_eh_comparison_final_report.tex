\section{Setup and Conventions}
This report compares a Matchete-derived Lagrangian to a reference action
\begin{equation}
\mathcal{L}_{\mathrm{ref}} = \Lambda_{\mathrm{ref}} \sqrt{-g} + s_{\mathrm{EH}}\, \frac{2}{\kappa_{\mathrm{ref}}^2} \sqrt{-g} R
\end{equation}
with reference coefficients $\Lambda_{\mathrm{ref}} = LambdaRefFinal$, $\kappa_{\mathrm{ref}} = KappaRefFinal$, and $s_{\mathrm{EH}} = -1$.
The Matchete input is normalized by setting $hbar = 1$ and discarding all terms containing negative powers of $\epsilon$.
If canonical normalization is enabled, the input quadratic sector is rescaled to the target sign $s_{\mathrm{kin}} = -1$ using an extracted symbolic factor $Z_h$. The raw factor used in the computation is:
\begin{verbatim}
(M^2*\[Kappa]^2*(1 + Log[\[Mu]bar2/M^2]))/24
\end{verbatim}
\begin{equation}
\beta^2 = \frac{s_{\mathrm{kin}}}{Z_h}.
\end{equation}
