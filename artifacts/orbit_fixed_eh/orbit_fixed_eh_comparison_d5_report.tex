\section{Setup and Conventions}
This report compares a Matchete-derived Lagrangian to a fixed reference action
\begin{equation}
\mathcal{L}_{\mathrm{ref}} = \Lambda_{\mathrm{ref}} \sqrt{-g} + \frac{2}{\kappa_{\mathrm{ref}}^2} \sqrt{-g} R
\end{equation}
with fixed values $\Lambda_{\mathrm{ref}} = 1$ and $\kappa_{\mathrm{ref}} = 1$.
The Matchete input is normalized by setting $hbar = 1$ and discarding all terms containing negative powers of $\epsilon$.
\section{Reference Support Through Mass Dimension 6}
The supported EH plus cosmological sectors are $\{n_h, 0\}$ for $1 \le n_h \le 6$ together with $\{2,2\}$, $\{3,2\}$, and $\{4,2\}$.
